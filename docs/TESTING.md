# Как протестировать Островок

Это рабочий MVP: Flutter-клиент + Go API. Авторизации и оплаты нет специально.

## Что должно быть запущено

Два процесса:

1. API: `.\scripts\run-backend.ps1` → http://127.0.0.1:8080
2. Приложение: `.\scripts\run-mobile.ps1`

На Windows без Pixel-эмулятора скрипт открывает **Microsoft Edge**:

- компьютер: http://127.0.0.1:5173
- телефон в той же Wi‑Fi: http://\<IP-компьютера\>:5173  
  (сейчас типичный адрес `http://192.168.0.139:5173`)

Проверка, что сервис жив:

- http://127.0.0.1:8080/health
- http://127.0.0.1:8080/v1/catalog
- фото: http://127.0.0.1:8080/static/places/ht-florence.jpg

## Сценарий для жюри (5–7 минут)

1. **Онбординг**  
   Выберите Италию и Грецию, приоритеты «Море» и «Города» → Готово.  
   Либо нажмите **Пропустить** — колода начнётся с универсального среднего отеля.

2. **Карточки, фото и Postgres**  
   На карточке фото места. Свайп вправо — лайк, влево — мимо.  
   Запрос уходит в Go, свайп пишется в `user_swipes`, следующая карточка уже с пересчитанными тегами.  
   Под описанием строка **«ИИ: …»**. В `/health` поле `"store":"postgresql"`.

3. **Обучение модели**  
   Поставьте 2–3 лайка на море и 1 дизлайк на бюджетный хостел.  
   Следующие карточки должны чаще показывать море/пляж и реже «мимо»-теги.  
   ИИ учится сразу, без перезапуска.

4. **Подробности**  
   «Подробнее» → фото, теги, удобства, отзывы → Нравится / Мимо.

5. **Агент**  
   Нижняя вкладка. Чипы: Подобрать, Забронировать, Отложить бронь, Менеджер.  
   Сначала сделайте хотя бы один лайк, затем «Забронировать».  
   В ответе появятся номера заявки `bkg-…` и тикета `tkt-…`.

6. **Кабинет**  
   Статус «API подключён».  
   У лайков кнопки **Заявка** и **Отложить**.  
   Список заявок внизу.

7. **Офлайн**  
   Остановите API (Ctrl+C в окне бэкенда) и обновите кабинет.  
   Приложение остаётся на локальном каталоге с теми же фото из `assets/places`.

## Автотесты

```powershell
.\scripts\check.ps1
.\scripts\check-mobile.ps1
```

Проверяют ранжирование ИИ, API заявок и то, что универсальный профиль начинает со среднего отеля.

## Как устроен ИИ-подбор

Это не ChatGPT и не облачный ключ. Модель на сервере и в приложении одинаковая:

- онбординг задаёт стартовый профиль (страны, теги, бюджет);
- каждый свайп усиливает или штрафует теги, тип жилья, бюджет и страну;
- более поздние свайпы весят чуть больше;
- MMR не даёт колоде застрять на пяти отелях подряд;
- карточка получает короткую фразу `whyRecommended`.

Код: `backend/internal/recommend` и `mobile/lib/services/recommendation_engine.dart`.
