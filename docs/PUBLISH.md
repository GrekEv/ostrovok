# Как выложить Островок, чтобы его потыкали

Нужны **две разные вещи**:

1. **GitHub** — код. Жюри видит репозиторий.
2. **Публичная ссылка** — собранное веб-приложение. Открывается в браузере телефона без установки.

GitHub сам Go-сервер не запускает. Веб-версия на GitHub Pages работает с встроенным каталогом (онбординг, карточки, свайпы, агент в офлайне). Живые заявки `bkg-…` на сервере появятся только если отдельно выложить API.

## Быстрый путь для тестеров

Один раз на вашем компьютере:

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\publish-github.ps1
```

Скрипт:

1. Проверит Git и GitHub CLI.
2. Откроет браузер для входа в GitHub, если вы ещё не вошли.
3. Создаст **публичный** репозиторий `ostrovok` (если его нет).
4. Загрузит код.
5. Включит GitHub Pages.

Через 2–5 минут после загрузки откройте:

```text
https://<ваш-логин>.github.io/ostrovok/
```

Эту ссылку и отправляйте тестерам. Репозиторий с кодом:

```text
https://github.com/<ваш-логин>/ostrovok
```

Пока сборка идёт, статус видно во вкладке **Actions** репозитория.

## Что делают тестеры

Открывают ссылку `.github.io` в Chrome / Safari / Edge. Устанавливать приложение не нужно.

Сценарий тот же, что в [TESTING.md](TESTING.md): страны → свайпы → агент. В кабинете будет режим без облачного API, если API не выложен.

## Запуск у себя на компьютере (не для чужих)

Это не публикация, а локальный запуск:

```powershell
.\scripts\run-backend.ps1
.\scripts\run-mobile.ps1
```

Приложение: http://127.0.0.1:5173  
API: http://127.0.0.1:8080/health

Чужой человек из интернета сюда не попадёт.

## По желанию: выложить Go API

1. Заведите аккаунт на [Render](https://render.com) и подключите тот же GitHub-репозиторий.
2. Render подхватит `render.yaml` и соберёт Docker-образ API.
3. Скопируйте HTTPS-адрес сервиса, например `https://ostrovok-api.onrender.com`.
4. В `.github/workflows/pages.yml` добавьте к `flutter build web`:

   ```text
   --dart-define=OSTROVOK_API_URL=https://ostrovok-api.onrender.com
   ```

5. Снова сделайте push в `main`.

Без этого шага веб-версия всё равно открывается и даёт потыкать интерфейс.

## APK на Android

Когда веб-ссылки мало:

```powershell
subst Z: "D:\Разработка\Ostrovok"
cd Z:\mobile
flutter build apk --release
```

Файл `mobile\build\app\outputs\flutter-apk\app-release.apk` можно прикрепить в GitHub → **Releases**. Тестер включает «установку из неизвестных источников».

iPhone чужим людям так не раздать: нужен Mac и TestFlight.
